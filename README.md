# Projeto - Cálculo de Energia

Este projeto em Pyton foi desenvolvido para cálcular o valor médio de consumo e custo
estimado de aparelhos eletrônicos, com o ciclo de **Entrada -> Processamento -> Saída.

O programa solicita o **Nome do aparelho** sua **Potência em watts** e o **Tempo médio de uso diario**,
calcula a média com os dados de potência e tempo médio usado e mostra o Aparelho, Consumo estimado e o Custo estimado por seu uso.
